# Mehta Clinic — Project Notes

## Goals
- Simple and clean app for patients and clinic staff
- Online appointment booking
- WhatsApp reminders
- UPI and card payments
- Admin dashboard with reports

## Out of Scope (for v1)
- Teleconsultation (later phase)
- Advanced inventory management

## Open Questions
- Should patients be able to reschedule from the app?
- How many clinic locations initially?
- Do we need integration with any existing system?
